# Nixon Per-Screen Polish (Phase D) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the Nixon redesign screen by screen: unified page chrome (headers, tabs, segmented controls, buttons, switch), the collapsible icon sidebar with the engraved wordmark, the typewriter-on-paper transcript and reel label, the Today timeline as a tape log, the Meetings list as a tape log, the People/Settings/Onboarding re-skins, state-aware tray icons, the pill-to-panel geometry pass, and the Plan 1/2 residuals.

**Architecture:** Shared chrome becomes three small components (`PageHeader`, `SegmentedControl`, a re-skinned `Switch`) used everywhere so per-screen work is mostly swapping markup. The reel ordinal is a `ROW_NUMBER()` column added to the meetings list query and threaded through `MeetingListRow` → `Meeting` → `DashboardMeeting`. The channel strip moves above the tabs by lifting `useSpeakers` to the page. Tray state icons are generated PNGs from an SVG and set via `tray.set_icon` on each state change. Every task ends with lint/test/tsc/gates and shrinks or holds the file-size ratchet.

**Tech Stack:** Next.js 14 / React 18 / Tailwind 3 (Nixon tokens; `[transition-duration:…]` not `duration-[…]`), Radix, lucide-react 0.469, Vitest + Testing Library; Tauri 2.6 (`tray-icon` feature), Rust + sqlx.

**Spec:** `specs/0057-nixon-rebrand-and-tape-deck-redesign.md` — "Decisions locked" 3/4/5/10 and §4 are binding; "Plan 1 residuals" and "Plan 2 residuals" are scope for Task 1 and Task 9. Plans 1 and 2 are on `feat/0057-nixon-rebrand`; this plan continues there.
